# THE EMERGENT TABLE // @helliveshere

Home for HEL recipes. Simple GitHub-web-only system.

## How this works (you only use github.com website)
1. This repo IS your website when GitHub Pages is on.
2. Each recipe is one markdown file in `/recipes/`
3. Images go in `/images/` - just drag & drop on github.com
4. Share the Pages link everywhere: Substack, Instagram, HEL.

## Folder map
```
/emergent-table/
  index.md  <- your landing page (auto lists recipes)
  recipes/
    TEMPLATE.md <- duplicate this for each new Sunday
    sunday-01-one-cabbage-three-dishes.md
  images/
    sunday-01-cabbage-rolls.jpg (you upload)
```

## To add a new recipe on github.com (30 sec)
1. Go to `recipes/` folder on github.com
2. Click `Add file > Create new file`
3. Name it: `sunday-02-what-needed-to-be-used.md`
4. Copy/paste contents of `TEMPLATE.md`
5. Fill it in, scroll down, click `Commit changes`
6. Done - your site auto-updates.
